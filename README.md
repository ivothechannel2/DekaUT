**DekaUT**



DekaUT is a basic concatenation-based vocal synthesis software developed in Python, inspired by the classic UTAU architecture. It doesn't use Artificial Intelligence to generate the synthesis (but it does use it for coding; please don't judge me, I don't know how to code at all, I'm just a UTAU and VOCALOID fan who wanted to make his own program...), but rather traditional digital audio processing (DSP) algorithms.



**Features**

\- Intuitive graphical interface with Piano Roll (Tkinter).



\- Audio engine based on Librosa and SciPy for pitch shifting and time stretching.



\- Only one voicebank is used (the program is in beta!).



**Requirements and Installation**

Make sure you have Python installed and run the following command in your terminal to install the necessary libraries:



```bash

pip install numpy librosa sounddevice scipy

```

**To start the program, run:**

```bash

python dekaut\_app.py

```
